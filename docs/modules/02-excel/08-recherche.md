## Fonction RECHERCHEV
Recherche une valeur dans un tableau vertical.

- La valeur recherchée doit être dans la première colonne
- Retourne une information associée

⚠️ Sensible à la structure du tableau.

## Validation des données
Limite les valeurs que l’utilisateur peut entrer.

- Listes déroulantes
- Plages numériques
- Messages d’erreur
