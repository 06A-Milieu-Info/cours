# Rechercher l'information sur la profession

Avant d'analyser une entreprise ou un poste, il faut d'abord savoir où chercher.

Le but n'est pas d'accumuler beaucoup de liens. Le but est de trouver des sources utiles, variées et fiables.

## Quelles sources utiliser

Voici quelques sources utiles pour ce module :

- le site officiel d'une entreprise
- la section carrières (habituellement en bas de page)
- une offre d'emploi publiée par l'entreprise (Indeed, LinkedIn, Glassdoor)
- un répertoire d'entreprises
- un répertoire de professions
- un site gouvernemental ou institutionnel
- une source liée à une visite ou à une conférence

## Ce qu'on cherche

Quand vous faites une recherche, essayez de répondre à des questions simples :

- Quelle est la profession ou le poste visé ?
- Dans quel milieu de travail retrouve-t-on ce poste ?
- Quelles tâches sont associées à ce poste ?
- Quelles compétences semblent demandées ?
- Quelles entreprises de la région de Québec embauchent dans ce domaine ?

## Reconnaître une source fiable

Une source n'est pas fiable seulement parce qu'elle arrive en premier dans les résultats de recherche.

Avant d'utiliser une information, demandez-vous :

- qui publie cette information
- pourquoi elle est publiée
- si elle est récente
- si elle correspond vraiment au sujet recherché
- si une autre source permet de la confirmer

Exemple de source fiable :

- un article publié sur le site officiel de CGI : [Optimisation par l'IA générative et l'informatique quantique](https://www.cgi.com/fr/blogue/intelligence-artificielle/optimisation-ia-generative-informatique-quantique-accelerer-simplifier-processus-decisionnels-complexes-chaine-approvisionnement), parce qu'il s'agit d'un contenu provenant directement de l'entreprise et lié à son domaine d'activité

Exemple de source moins fiable :

- une discussion Reddit comme [ce fil de discussion](https://www.reddit.com/r/france/comments/13c5obs/estce_que_lia_est_un_danger_pour_nos_m%C3%A9tiers_et/), parce qu'il s'agit d'opinions ou de témoignages non vérifiés, sans garantie de rigueur ni de représentativité

## Utiliser l'IA générative pour la recherche

De plus en plus de personnes utilisent des outils d'IA générative pour commencer une recherche.

Un des outils qui sera démontré est **[NotebookLM](https://notebooklm.google/)**, qui peut aider à regrouper des sources, à résumer de l'information et à faire ressortir des éléments importants à partir des documents consultés.

Cela peut être utile pour :

- trouver des mots-clés
- repérer des pistes de recherche
- obtenir un premier résumé d'un sujet
- comparer rapidement ce que disent plusieurs sources

Par contre, les bons réflexes restent les mêmes.

Une réponse générée par l'IA ne doit pas être acceptée automatiquement comme vraie.

## Bons réflexes

- vérifiez toujours les sources en cliquant dessus
- assurez-vous que les sources existent vraiment
- vérifiez que les sources disent réellement ce que le résumé affirme
- comparez l'information avec d'autres sources fiables

Si l'outil ne cite pas clairement ses sources, il n'y a **aucune façon de confirmer** si l'information est véridique.

L'IA peut aider à la recherche, mais elle ne remplace pas la vérification. Vérifiez et choisissez toutes vos sources sans aucune exception.

## Diversifier l'information recueillie

Une seule source donne rarement un portrait complet.

Essayez de combiner :

- une source sur l'entreprise
- une source sur le poste
- une source sur le domaine

Cette diversité aide à éviter les descriptions trop vagues ou trop promotionnelles.

## Utiliser les outils de recherche correctement

Quelques bons réflexes :

- cherchez avec des mots-clés précis
- testez plusieurs formulations
- comparez plusieurs résultats
- notez vos sources au fur et à mesure

Exemples de recherches utiles :

- développeur d'application Québec
- entreprise cybersécurité Québec carrières
- analyste-programmeur offre d'emploi Québec

## Ce qu'il faut éviter

- prendre la première source sans vérification
- se fier à une seule page Web
- utiliser une source trop vague ou non attribuée
- copier du texte sans avoir validé l'information

## Activité
Dans le cadre de votre travail pratique, vous devrez trouver des sources pertinentes. Choisissez une des trois entreprises que vous aurez à analyser et effectuez les tâches suivantes:

Trouvez trois sources différentes :

1. une source sur l'entreprise;
2. une source sur un poste en informatique lié à cette entreprise;
3. une source plus générale sur le secteur d'activité (financier, secteur public, commerce, etc.) de l'entreprise.
