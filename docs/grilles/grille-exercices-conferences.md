# Grille d'évaluation — Exercices, conférences et visites d'entreprises

**Valeur : 10 % du cours**

---

### 1) Lab Vocabulaire (10 %)

| Niveau | Description | Note |
|------|-------------|------|
| **Excellent** | Lab remis et toutes les questions répondues. | 100 % |
| **Invalide** | Lab non remis ou réponses absentes. | 0 % |

---

### 2) Conférence Informatique à tous les niveaux (20 %)

| Niveau | Description | Note |
|------|-------------|------|
| **Excellent** | Résumé remis, contenu clair et réflexion personnelle pertinente. | 100 % |
| **Suffisant** | Résumé remis, mais contenu superficiel, incomplet ou réflexion peu développée. | 60 % |
| **Invalide** | Non remis. | 0 % |

---

### 3) Présence à la conférence du Ministère de la cybersécurité (20 %)

| **Excellent** | Présence confirmée à la conférence. | 100 % |
| **Invalide** | Absence à la conférence. | 0 % |
